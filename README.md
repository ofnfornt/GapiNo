## 📸 معرفی پروژه

GapiNo یک شبکه اجتماعی حرفه‌ای تحت وب است که با هدف ایجاد تجربه‌ای مدرن، سریع و زیبا ساخته می‌شود.

این پروژه با الهام از تجربه کاربری شبکه‌های اجتماعی محبوب طراحی شده و برای موبایل، تبلت و دسکتاپ کاملاً Responsive خواهد بود.

# 🚀 اجرای پروژه

## پیش‌نیازها

نصب کنید:

- Node.js
- Git
- Docker (اختیاری)

بررسی نصب:

```bash
node -v
npm -v
```

## دریافت پروژه

```bash
git clone https://github.com/ofnfornt/GapiNo.git
```

ورود به پوشه:

```bash
cd GapiNo
```

## نصب وابستگی‌ها

```bash
npm install
```

## اجرا

```bash
npm start
```

سپس مرورگر:

```
http://localhost:10000
```

---

# 🐳 اجرا با Docker

ساخت Image:

```bash
docker build -t gapino .
```

اجرا:

```bash
docker run -p 10000:10000 gapino
```

---

# ☁️ Deploy روی Render

1. اتصال GitHub به Render
2. انتخاب مخزن GapiNo
3. انتخاب Environment: Docker
4. انتخاب Branch: main
5. Deploy
